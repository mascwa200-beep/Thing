RE-ENCODING NOTICE (applies to every raster file in this folder)
--------------------------------------------------------------------------
All raster diagrams are bundled as WebP, re-encoded from the originals at quality 85 and
scaled down where they exceeded 1280 pixels wide. Nothing is cropped, recoloured, overlaid
or otherwise altered: the change is one of resolution and file format only, made so the
corpus fits a phone (68 MB to 31 MB) without changing what the reader sees — the app draws
these at 260dp on Android and 620dp on the desktop, so the discarded pixels were never
displayed. Where a licence requires that modifications be indicated, this paragraph is that
indication. Most SVG files are bundled unchanged, as vector. Some diagrams that were
originally vector are bundled as WebP instead: any such file was rendered from the original
SVG at 1280 pixels wide and composited onto a white background, which is the same background
the rest of the line art here already carries. No cropping, recolouring or overlay — only
resolution and file format — and the Commons "File:" link recorded for each still points at
the original vector work. See the fuller note in ../NOTICE.txt, which governs both folders.
